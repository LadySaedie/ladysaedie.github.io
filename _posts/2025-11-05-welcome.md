HOW TO OPEN THE BLOG IN GITHUB CODESPACES AND PREVIEW CHANGES

1. Sign in to GitHub.
2. Open the Lady Saedie blog repository.
3. Click the green <> Code button.
4. Select the Codespaces tab, if it is not already selected.
5. Open an existing Codespace. If there isn't one, click the + icon to create a new Codespace.
6. Wait for the Codespace to start. A newly created Codespace may take a little while to build.
7. If the terminal is not visible, open it by selecting Terminal > New Terminal from the menu.
8. In the terminal, enter:  
    `bundle exec jekyll serve`

9. If Jekyll reports that gems are missing or cannot be installed because of a permissions error, stop the running command by pressing Ctrl+C, then enter these commands one at a time:  
    `bundle config set --local path 'vendor/bundle'`  
    `bundle install`  
    `bundle exec jekyll serve`  
The first command tells bundler to install the required gems inside the blog's own folder, where the Codespace has permission to write them.

10. Wait while Jekyll builds the preview website. When the notification appears in the bottom-right corner, click Open in Browser.

11. If you miss the notification:  
    Click the PORTS tab at the bottom of the Codespace.  
    Find port 4000.  
    Hover over its Forwarded Address.  
    Click the globe icon labelled Open in Browser.  
GitHub Codespaces automatically forwards a port when an application prints a localhost address in the terminal. The forwarded port can then be opened in a browser for testing.

12. If the PORTS tab is not visible:  
Press Ctrl+Shift+P  
Type ports  
Select Ports: Focus on Ports View.  

IMPORTANT NOTES
- Leave the terminal running while previewing the website.
- To stop Jekyll, click inside the terminal and press Ctrl+C.
- If an existing Codespace has merely stopped, reopen it and run:  
    `bundle exec jekyll serve`  
- If the Codespace has been deleted and you create a new one, you may need to run the Bundler configuration and installation commands again:  
    `bundle config set --local path 'vendor/bundle'`  
    `bundle install`  
    `bundle exec jekyll serve`  
Closing the browser tab does not necessarily stop the Codespace. A Codespace continues running until it is stopped explicitly or reaches its inactivity timeout.  

**Leaving Codespace**  
Click inside the terminal and press Ctrl+C to stop the Jekyll preview server  
Then, press Ctrl+Shift+P to open the Command Palette  
Type:  
    `stop codespace`  
Select Codespaces: Stop Codespace  
Wait for the Codespace to stop, and then close the browser tab.

Every post must START with the 'front matter', including the three dashes top and bottom. See sample below.  

\- - -  
title: "Title of the Post in Quote Marks"   
description: Any description on only one line. No quote marks.  
date: 2024-12-01  
last_modified_at: 2025-04-21T00:00+02:00  
published: true  
categories: [One, Two, Seebelow]  
tags: [three, four, see below]  
excerpt: Any text you want. No quote marks.  
pin: false  
toc: true  
image:  
&nbsp; &nbsp; path: /assets/img/image-name.jpg  
&nbsp; &nbsp; alt: "...whatever text you want to appear under your image..."  
\- - -  
This is where your post text starts.

Every post must have the extension .md (not .txt!), e.g., 2025-01-01-New-Year.md  
TIP: I insert an optional date prefix in the filename, e.g., "ccyy-mm-dd-name-of-file.md" This allows me to keep the chronological order of posts when I add a post which was written earlier.

categories: (I renamed mine to 'catalogues' on the tab):  
one word, initial capital, comma and space inside square brackets.  
The first word is the main catalogue, followed by one subcatalogue only.  
E.g.,  
[Autobiographical, Adult or Child or Teenager] or  
[Family, Extended or Immediate] or  
[Fiction, Absurd or Crypto or Musings]  

tags: (I renamed mine to 'keywords' on the tab):  
Lower case, comma and space, multiple words between commas inside square brackets.  
E.g.,  
[any, more words, you think of]

SIMPLE MARKDOWN:

Two spaces at the end of a line will create `lf`  
Two 'Enter' at the end of a line will create `cr`  
To increase space between two paragraphs insert the following empty HTML \<div> tag and edit the variable 'em' digit:  
\<div style="margin-top: 2em;">\</div>  

`&nbsp;` &nbsp; &nbsp; to create an additional spaces  
\# h1 Heading  
\#\# h2 Heading  
\#\#\# h3 Heading  
\*\***bold**\*\*  
\**italic*\*  
\*\*\****bold and italic***\*\*\*  
> `>` blockquote  

Ordered list (just use numbers):  
1\.  
2\.  

Unordered list (just use hyphen):  
\-  
\-  

\ backslash before a character will 'escape' or show code text or real text, e.g.,  
\\--- on a new line will show three dashes not a divider line  

\``backtick (or backquote) before and after`\` will write the text as code.

Links:  
\[Name of link](https:known.url.com)  
\!\[Name of picture](picture-name.jpg)
